# ailaboratorydesk.com

The home of the AI Laboratory — <https://www.ailaboratorydesk.com>.

A static [Astro](https://astro.build) site deployed to GitHub Pages by GitHub Actions.
Case studies live in `src/content/case-studies/`, one Markdown file each.

```bash
npm ci
npm run dev    # http://localhost:4321
npm test       # type-check, build, and verify
```

See [AGENTS.md](AGENTS.md) for how to add a case study, build, test, deploy, and the data-security rules.
